# SeaTicket

SeaTicket is a ticketing system and AI agent that support your community. SeaTicket’s vision is to build an AI agent that helps you resolve community support issues, so you can focus on building.

SeaTicket connects email, GitHub, Discord, and other channels in one AI-native ticketing system.

## What’s special about SeaTicket

* SeaTicket excels at resolving community support issues from multiple channels, such as GitHub, Discord, Email, and more.
* SeaTicket’s agent monitors new issues and other events to proactively suggest actions for those events.


## History

SeaTicket was developed by the team behind Seafile, following years of experience building open-source cloud storage software and supporting a global user community.

From that experience, we consistently ran into the same problems:

* No single tool to aggregate support questions, issue reports, and product feedback from multiple channels.
* The same questions repeated across different platforms with no way to automate responses.
* Complex issues requiring significant investigation time, with solutions never captured for future use.
* Important feedback getting lost among general support questions, leaving many inquiries unanswered.

In response to these challenges, we created SeaTicket, an AI-powered unified issue management system.
